# Testing Guide

The current commands, manual scenarios, pass criteria, and known limitations are in the [Pain Assessment Test Plan](../testing/test-plan.md). Run them from the repository root and record results against the actual commit under review.

Feature-specific screenshots and verification notes live under [docs/testing](../testing/). Their results describe the branch and date named in each record; they do not prove current production behavior. Use synthetic data and distinguish mocked EmailJS tests from an owner-authorized live delivery test.
